# תוכנית אימונים

אפליקציית ווב (PWA) למעקב אחרי תוכנית אימונים עם התקדמות אוטומטית אחרי כל אימון.

## איך ההתקדמות עובדת
- בכל אימון שמסומן "סיימתי", סט אחד עולה בחזרה אחת: קודם סט 1 עד המקסימום של הטווח, אחר כך סט 2, וכן הלאה.
- כשכל הסטים במקסימום, האימון הבא נעשה כך, ובסיומו המשקל עולה בקפיצה שהוגדרה והחזרות חוזרות למינימום.
- אם בסט כלשהו נעשו פחות חזרות מהיעד, התרגיל נשאר כמו שהוא. תרגיל שדולג לא משתנה.

## הפעלה ב־GitHub Pages
Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save.
אחרי דקה האתר זמין ב־`https://<user>.github.io/<repo>/`. בטלפון: תפריט הדפדפן → "הוסף למסך הבית".

הנתונים נשמרים מקומית בדפדפן (localStorage). גיבוי וייבוא — במסך ההגדרות.
